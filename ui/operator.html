What happens when I press Send?

This workstation creates a fresh timestamp and random command nonce, then authenticates the command with HMAC-SHA256. Windows validates the command before forwarding any write.

A safety violation is checked by the gateway, so the input does not silently hide outside-policy values. Network failures are displayed as errors.

Choose a controlled demonstration

Normal operator inputs already demonstrate range checks. These scenarios deliberately alter identity, signatures, timestamps, or register access to exercise the other checks.

The full suite sends real commands, including legitimate baseline writes. It changes the simulator's chlorine and valve values. It never edits your Windows evidence database.

Windows WaterGuard address

Open Command Prompt on Windows, type ipconfig, and use the Wi-Fi IPv4 address. The local Ubuntu UI is not the Windows gateway.

Before your presentation

Use the IPv4 address shown by the Windows launcher. Its authorized Device A address must match Ubuntu's bridged network address.

The app checks the command-key fingerprint and source-IP mapping. A self-signed lab certificate is expected. Certificate validation is relaxed for this lab connection; this is not production server authentication.

Keep both application launchers open. On Windows, open https://localhost:8443/ to show the plant and protected encryption proof.
